# stoat-soundboard

A soundboard bot for stoat

## Requirements

- This software uses the [Bun](https://bun.sh) runtime. (install with: `curl -fsSL https://bun.sh/install | bash`)
- Create a "public" folder, the bot expects the audio files to be placed there.
- Create a .env file with the following entries
  - BOT_TOKEN="..."
  - CHANNEL_ID="..."
  - PORT=3000
